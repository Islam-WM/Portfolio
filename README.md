# Islam Mansour — Portfolio

A responsive, accessible static portfolio site for data-science and machine-learning applications.

## Preview locally

Open `index.html` directly in a browser, or serve this folder with any static web server.

## Structure

- `index.html` — content and page structure
- `styles.css` — responsive visual design
- `script.js` — mobile navigation, project filters and reveal effects
- `assets/` — profile image
- `output/` — downloadable CV in PDF and Word formats

## Personalization

The project descriptions use only facts from the supplied CV. Add GitHub or live-demo links to the project cards once those URLs are available.
